# NFC Card Admin (web)

Веб-панель для выпуска физических NFC-карт: логин администратора, создание
карточки (профиль / внешний сайт / картинка / wifi / произвольный payload) за
несколько секунд, публичная страница `/u/<slug>` (то, что открывается при
поднесении карты), и запись прямо на метку из браузера через Web NFC API
(Chrome на Android).

## Запуск локально

```
npm install
npm start
```
Открыть http://localhost:3000, логин `admin` / `admin123`.

## Переменные окружения (production)

| Переменная         | Обязательна | Назначение                                                                 |
|---------------------|:-----------:|------------------------------------------------------------------------------|
| `NODE_ENV=production` | да        | включает secure-cookies и предупреждение о SESSION_SECRET                    |
| `SESSION_SECRET`      | да (prod) | случайная строка для подписи сессионных cookie; без неё сессии сбрасываются при каждом перезапуске |
| `PORT`                 | нет       | порт (хостинг обычно подставляет сам)                                       |
| `PUBLIC_BASE_URL`      | нет       | публичный HTTPS-адрес для payload'ов (`https://ваш-домен`); если не задан — вычисляется из заголовков запроса |

## Важно про данные и физические карты

Хранилище — файл `data/db.json` на диске контейнера. На части бесплатных
тарифов хостингов диск не гарантированно переживает **новый деплой** (обычный
перезапуск/засыпание от бездействия — переживает, а вот `git push` с новым
кодом может создать чистый контейнер).

Так как физические карты после записи существуют вечно и продолжают
указывать на `/u/<slug>`, **обязательно делайте экспорт перед каждым
деплоем новой версии кода**: «Экспорт» в панели → сохранить `.json` →
после деплоя, если список карточек пуст, восстановить через «Импорт».

Отдельное ограничение: загруженные через форму картинки (`public/uploads/`)
в бэкап не входят — для карточек типа «Картинка», которые должны жить долго,
надёжнее указывать внешнюю ссылку на картинку, а не загружать файл.

## Деплой на Render.com (бесплатно, без карты)

1. Запушьте репозиторий на GitHub.
2. На render.com: New → Blueprint → выбрать репозиторий → Render найдёт
   `render.yaml` в корне и настроит сервис автоматически.
3. Задать `PUBLIC_BASE_URL` в Environment на реальный адрес после первого деплоя
   (Render выдаёт вид `https://nfc-card-web.onrender.com`).
