# NFC Card Admin (web)

Веб-панель для выпуска физических NFC-карт: логин администратора, создание
карточки (профиль / внешний сайт / картинка / wifi / произвольный payload) за
несколько секунд, публичная страница `/u/<slug>` (то, что открывается при
поднесении карты), и запись прямо на метку из браузера через Web NFC API
(Chrome на Android).

Также: редактирование и дублирование карточек, массовое создание профилей из
CSV (для мероприятий с большим числом людей), счётчик просмотров на карточку,
скачивание QR-кода как PNG, поиск и статистика по типам в дашборде,
экспорт/импорт всей базы для резервного копирования, переключатель языка на
публичной странице карточки (RU/EN/FR/DE/ES/IT).

**Безопасность входа**: после 5 неверных попыток подряд аккаунт блокируется на
15 минут (независимо от IP), плюс нарастающая задержка и лимит попыток по IP.
Восстановление доступа — через одноразовый код восстановления
(«Пароль» → «Создать код восстановления»), который нужно сохранить заранее:
без него, если пароль забыт, доступ восстановить нельзя.

## Запуск локально

```
npm install
npm start
```
Открыть http://localhost:3000, логин `admin` / `admin123`.

## Переменные окружения (production)

| Переменная         | Обязательна | Назначение                                                                 |
|---------------------|:-----------:|------------------------------------------------------------------------------|
| `NODE_ENV=production` | да        | включает secure-cookies и предупреждение о SESSION_SECRET                    |
| `SESSION_SECRET`      | да (prod) | случайная строка для подписи сессионных cookie; без неё сессии сбрасываются при каждом перезапуске |
| `PORT`                 | нет       | порт (хостинг обычно подставляет сам)                                       |
| `PUBLIC_BASE_URL`      | нет       | публичный HTTPS-адрес для payload'ов (`https://ваш-домен`); если не задан — вычисляется из заголовков запроса |
| `REDIS_URL`            | нет (но настоятельно рекомендуется в prod) | `rediss://default:<password>@<host>:6379` — постоянное хранилище карточек (см. ниже) |
| `CLOUDINARY_URL`       | нет (но рекомендуется в prod) | строка вида `cloudinary://<key>:<secret>@<cloud_name>` из cloudinary.com — загруженные фото/картинки хранятся там вместо диска (см. ниже) |
| `SENTRY_DSN`           | нет       | DSN из sentry.io — если задан, все необработанные ошибки сервера автоматически отправляются в Sentry |

## Данные и физические карты

Без `REDIS_URL` карточки хранятся только в файле `data/db.json` на диске
контейнера. На бесплатных тарифах хостингов (в т.ч. Render free) этот диск
**не переживает новый деплой** — каждый `git push` с новым кодом создаёт
чистый контейнер, и все карточки, созданные после предыдущего деплоя,
теряются.

С заданным `REDIS_URL` (например бесплатная база на upstash.com) каждое
изменение сразу дублируется в Redis, а при старте сервер подхватывает
последнее состояние оттуда — карточки переживают любой редеплой. Локальный
файл при этом остаётся как быстрый кэш, но уже не единственный источник
истины.

Даже с Redis рекомендуется иногда делать «Экспорт» в панели как
дополнительный бэкап на свой компьютер.

Загруженные через форму картинки и фото профиля хранятся на локальном диске
(`public/uploads/`) и **тоже теряются при редеплое** — если не задан
`CLOUDINARY_URL`. С заданным `CLOUDINARY_URL` (бесплатный аккаунт на
cloudinary.com, 25GB, без карты) все новые загрузки автоматически идут в
Cloudinary и получают постоянную ссылку, не зависящую от диска контейнера.

## Отслеживание ошибок (Sentry, опционально)

Если задать `SENTRY_DSN` (бесплатный аккаунт на sentry.io), все необработанные
ошибки на сервере автоматически прилетают в Sentry с полным стектрейсом —
узнаёте о поломке раньше, чем о ней напишет пользователь.

## Двухфакторная аутентификация (2FA)

В разделе «Пароль» админ-панели можно включить вход по коду из приложения
(Google Authenticator, Microsoft Authenticator, Authy и т.п.) в дополнение к
паролю. Секрет хранится в базе данных (Redis/файл), отдельная переменная
окружения не нужна.

## Светлая тема

Переключатель (значок луны/солнца) в правом верхнем углу — выбор сохраняется
в браузере устройства.

## Деплой на Render.com (бесплатно, без карты)

1. Запушьте репозиторий на GitHub.
2. На render.com: New → Blueprint → выбрать репозиторий → Render найдёт
   `render.yaml` в корне и настроит сервис автоматически.
3. Задать `PUBLIC_BASE_URL` в Environment на реальный адрес после первого деплоя
   (Render выдаёт вид `https://nfc-card-web.onrender.com`).
